# Security & publication policy

- Do not commit personal identifiers (CPF, RG), full certificates containing them, invoices, third-party logos without permission, customer data, emails, real incident logs, IP addresses, internal hostnames, business contracts, API tokens or passwords.
- The diagrams and cases are sanitized, qualitative descriptions; no real company configurations should be reproduced.
- Only use the provided tools in environments that you own or are explicitly authorized to test.
- If a vulnerability is discovered in third-party software, report it via the vendor's coordinated vulnerability disclosure process.
- The site is static and has no analytics, cookies or third-party API calls. Google Fonts are fetched if network is available; local system fallbacks are defined.
